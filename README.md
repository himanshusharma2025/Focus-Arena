Description:- Focus Arena is Basically gamigied focus + productivity web app.Help users to enjoy their working time and complete sessions to gain Xp and do levelups.With help of Focus Arena users code with fun.

Features of Focus Arena:- 

1. Focus Timer.
2. Xp System.
3. HP System.
4. Smooth Animations.
5. Gamified UI Experience.
6. Full Game Like Feeling.

Tech Stack:-

Reactjs + Tailwind CSS + Framer Motion.

How it works:-

1. User starts focus session.
2. Complete Session gives Xp.
3. During Session users add tasks.
4. Progress motivates but it helps to built consistency.

Installation:-

git clone <repo>.
npm install.
npm run dev.

Future Plans:-

Daily Quests and boost productivity.

Why I built This:-

I wanted to make productivity feel less boring and more like a game,so I built Focus Arena to combine focus sessions with RPG-style mechanics.It contains smooth animations and enjoy 25 mint session.
